### Vue d'ensemble

L'inference statistique est une branche de la statistique qui se concentre sur l'estimation des paramètres et les hypothèses dans un modèle. Elle utilise des méthodes pour déterminer si deux ou plus groupes indépendants ont des moyennes ou distributions différentes.

### Concepts clés

*   **Inférence statistique** : méthode utilisée pour estimer les paramètres d'un modèle.
*   **Estimation statistique**: processus de calcul qui permet de trouver une valeur approximative pour un paramètre inconnu dans un modèle. 
*   **Hypothèses** : suppositions fausses sur la population ou le système étudié, utilisées comme point de départ pour les tests statistiques.
*   **Paramètres inconnus**: valeurs non connues qui sont estimées à partir des données observées.
